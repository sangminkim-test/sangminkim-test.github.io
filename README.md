# Sangmin Kim — Personal Profile

CV를 바탕으로 만든 개인 자기소개 페이지입니다. Pretendard와 흑백 바탕, 절제된 빨간색 포인트를 사용합니다.

한국어: https://sangminkim-test.github.io/

English: https://sangminkim-test.github.io/en/

## 구성

- `index.html`, `en/index.html`: 한국어·영어 자기소개, 활동, 수상, 학력과 교육
- `assets/style.css`: 공통 디자인과 반응형·테마 스타일
- `assets/theme-init.js`, `assets/site.js`: 테마 초기화와 전환
- `assets/fonts/`: Pretendard 1.3.9 웹폰트(400, 500)와 SIL OFL 라이선스
- `404.html`, `en/404.html`: 없는 페이지 안내
- `sitemap.xml`, `robots.txt`, `.nojekyll`: 기본 게시·검색 설정

상단 KO / EN으로 언어를 전환합니다. 태양·달 버튼으로 라이트·다크 테마를 전환하며 선택은 브라우저에 저장됩니다. 처음 방문하면 다크 테마로 표시됩니다.

## 수정

별도 설치나 빌드 없이 HTML/CSS/JavaScript를 그대로 사용할 수 있습니다. 자기소개는 `index.html`과 `en/index.html`에서 각 언어에 맞춰 수정합니다. 외부 추적 코드나 외부 폰트 요청은 없습니다. 수상 내역 8건을 모두 표시합니다.

GitHub Pages는 `main` 브랜치의 `/ (root)`를 게시하도록 설정합니다. `main`에 변경 내용을 커밋하면 갱신됩니다.

프로필의 GitHub와 Tistory 링크는 CV에 기재된 개인 계정입니다. Integrative Data Science는 CV에 따라 희망 전공으로 표기했습니다. 원본 CV·휴대전화·상세 주소·인증 정보는 포함하지 않았습니다.
